# Gold Examples

Real, lightly-cleaned bullets from the corpus, plus before->after transformations and full archetype
skeletons. Use these as the calibration target: this is exactly how good looks.

## Before -> After transformations (the core teaching device)

| Weak input | House-style rewrite |
|------------|--------------------|
| Responsible for managing the company's social media | Grew Instagram following 3x (1k->3k) in 4 months by running a 12-post/week content calendar |
| Helped organize the college fest | Spearheaded a 40-member team to run an 8k-footfall fest with Rs4L+ sponsorship across 16 stalls |
| Worked on a machine learning model for detecting pneumonia | Built a CNN hitting 96% accuracy, cutting pneumonia-detection time 100x (5 hrs -> 3 min) |
| Did an internship at a bank and learned a lot | Reduced false alerts 50% in a transaction-monitoring rule, validated across 57k alerts |
| Was part of the placement committee | 1/23 selected from 102 applicants to the Placement Cell; led outreach to 8+ recruiters |
| Good at competitive exams | Secured 99.75%ile in CAT (out of 3.3L candidates); AIR 604 in JEE Advanced |
| Led a team to improve sales | Drove 20%+ sales growth by launching an online marketplace across 3 start-up partners |
| Reduced costs at the plant | Saved Rs1.8Cr+ by installing IoT devices, cutting red-mud loss 30% across plant operations |

The moves in every rewrite: (1) swap the weak opener for an action verb, (2) put a number first,
(3) add a `by/via` method clause, (4) name the scope/scale, (5) cut to one line.

## Archetype CV skeletons (how a whole CV hangs together)

**Archetype A - Quant/Finance lateral (3+ yrs work ex), leads with experience:**
Header -> WORK EXPERIENCE (2 firms, side-labels: Pricing Tool / Attribution / Risk Modelling) ->
EDUCATION (CFA L1, IIT B.Tech 9.67) -> SCHOLASTIC (JEE AIR, case-comp wins) -> RESEARCH & INTERNSHIP.

**Archetype B - Engineering fresher, leads with education:**
Header -> EDUCATION (IIT/NIT, Dept Rank) -> SCHOLASTIC (CAT %ile, JEE, olympiads) -> INTERNSHIP
(HUL/PPO, side-labels: Role / Impact) -> PROJECTS (3 technical, side-labels) -> PoR -> EXTRA-CURRICULAR.

**Archetype C - Non-engineering / social-impact background:**
Header -> EDUCATION (Hons degree, medalist) -> ACADEMIC ACHIEVEMENTS & CERTIFICATIONS ->
INTERNSHIPS & PROJECT (field research, side-labels: Survey / Fieldwork) -> PoR (Editor, E-Summit) ->
EXTRA-CURRICULAR (social service, arts).

In all three: bullets are single-line, number-led, verb-opened, grouped under thematic side-labels,
with the year right-aligned. The difference is only *order* and *verb palette* - the grammar is identical.
