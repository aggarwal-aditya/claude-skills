# Review & Score Rubric

Use this when the user asks to rate, review, critique, or improve existing CV points. Score each
bullet, then give the single most useful fix. Be specific and concrete - quote the exact word to cut
or the number to add. Generic praise is useless here.

## Score each bullet on 6 criteria (1-2 points each, /10 with a bonus point for a standout result)

1. **Strong verb opener (2)** - past-tense action verb, not "Responsible for"/gerund/pronoun.
2. **Number front-loaded (2)** - a concrete figure, ideally in the first six words.
3. **Method shown (1)** - a by/via/through/using clause explaining *how*.
4. **Length & single line (1)** - ~12-18 words; doesn't wrap.
5. **Compression (1)** - symbols/abbreviations used; no fluff words; no closing period.
6. **Section fit (2)** - verb and metric match the section's job (see section-playbook.md);
   e.g. PoR shows scale, Scholastic shows selectivity, Experience shows business impact.
   **+1 bonus** for a genuinely strong, specific, credible result.

## Banding
- **9-10** strong, leave it. - **6-8** solid, one tweak. - **3-5** weak, rewrite. - **0-2** fluff, rebuild from scratch.

## Output format
For each bullet:
```
"<their bullet>"
Score: X/10
Fix: <one specific, actionable change - the word to cut or the number to add>
Rewrite: <the improved single-line bullet>   (only if score < 8)
```
Then finish with **Top 3 highest-leverage fixes** across the whole set (e.g. "every Experience bullet
is missing a number - add the rupee/percent figure" or "3 bullets open with 'Responsible for'").

## Common failure patterns to watch for
- No number anywhere -> the #1 problem; flag immediately.
- Activity described, not outcome ("Worked on a dashboard" vs "Cut reporting time 40% via a dashboard").
- Verb-section mismatch (e.g. "Participated" in Work Experience; should be an impact verb).
- Two lines / runs long -> cut adjectives, use `&` and `|`, drop articles.
- Repeated verb openers down a block -> diversify from verb-bank.md.
- Method without result, or result without method -> the best bullets have both.
